## 🤖 Claude Code とは？

Claude Code は、Anthropic が開発した **ターミナル（コマンドライン）で動く AI コーディングアシスタント**です。

- 💬 **自然言語で操作** — 「このファイルを整理して」と話しかけるだけ
- 📁 **ローカルファイルに直接アクセス** — PC 上のファイルを読み書きできる
- 🔍 **コード以外もOK** — CSV・テキスト・JSON など幅広いファイルに対応
- 🚀 **複数ファイルを横断して分析** — バラバラなデータも一括で処理

---

## ⚙️ 事前準備・セットアップ

### 必要なもの

| 項目 | 条件 |
|------|------|
| OS | macOS / Windows 11 / Linux |
| Claude アカウント | **Pro プラン以上**（月額 $20〜）が必要 |
| インターネット接続 | 必須 |

> ⚠️ 無料プランでは Claude Code を使用できません。

---

### Step 1: Claude Code をインストールする

#### macOS / Linux の場合

ターミナルを開いて以下を実行：

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

#### Windows の場合

**まず Git for Windows をインストール（必須）:**
1. [git-scm.com/download/win](https://git-scm.com/download/win) からダウンロード
2. インストーラーを実行（設定はすべてデフォルトでOK）
3. ターミナルを再起動

**次に PowerShell で以下を実行：**

```powershell
irm https://claude.ai/install.ps1 | iex
```

---

### Step 2: インストールを確認する

```bash
claude --version
```

バージョン番号が表示されれば成功！

---

### Step 3: ログインする

```bash
claude
```

初回起動時にブラウザが開くので、Claude アカウントでログインしてください。

## 📁 デモ用データの配置

### ダミーデータをデスクトップに配置する

```bash
# このリポジトリをクローン
git clone https://github.com/YOUR_USERNAME/claude-code-demo.git
cd claude-code-demo

# セットアップスクリプトを実行（ファイルをデスクトップに配置）
bash scripts/setup_demo.sh
```

実行後、デスクトップに以下のファイルが作成されます：

| ファイル | 内容 |
|----------|------|
| `sales_2024_Q1.csv` | 2024年Q1 売上データ |
| `sales_2024_Q2.csv` | 2024年Q2 売上データ |
| `customers.csv` | 顧客リスト |
| `project_memo_A.txt` | プロジェクトメモ（ECサイト） |
| `project_memo_B.txt` | プロジェクトメモ（DX推進） |
| `meeting_notes_0520.txt` | 会議メモ |
| `inventory.json` | 商品在庫データ |
| `employees.csv` | 従業員データ |

## 🎬 デモシナリオ

### Claude Code をデスクトップフォルダで起動する

```bash
cd ~/Desktop
claude
```

> 💡 **ポイント:** `cd` でデスクトップに移動してから `claude` を起動すると、そのフォルダ内のファイルを Claude が認識できます。

---

### 🎯 シナリオ 1：ファイルの全体把握（まず「すごい！」を体験）

**プロンプト:**
```
デスクトップにあるファイルをすべて確認して、どんなデータが入っているか日本語でまとめてください。
```

**期待される動き:**
- Claude が全ファイルを自動で読み込む
- ファイルごとの内容サマリーを出力
- データの関連性も分析してくれる

---

### 🎯 シナリオ 2：売上データの分析

**プロンプト:**
```
Q1とQ2の売上CSVを分析して、以下を教えてください：
1. 担当者ごとの合計売上
2. 商品カテゴリ別の売上
3. Q1→Q2での変化
```

**期待される動き:**
- 2つのCSVを横断して集計
- 担当者・商品ごとの数値を整理
- 増減トレンドもコメント

---

### 🎯 シナリオ 3：在庫アラートの検出

**プロンプト:**
```
inventory.jsonを見て、在庫数がmin_stockを下回っている商品を教えてください。発注が必要な商品を優先度順にリストアップしてください。
```

---

### 🎯 シナリオ 4：議事録からTODOリストを抽出

**プロンプト:**
```
meeting_notes_0520.txtを読んで、TODOリストを担当者別に整理してmarkdownで出力してください。
```

---

### 🎯 シナリオ 5：複数ファイルをまとめてレポート化（圧巻のデモ！）

**プロンプト:**
```
デスクトップのすべてのファイルを読み込んで、経営会議向けの週次サマリーレポートをmarkdown形式で作成してください。売上・在庫・プロジェクト状況・課題を含めてください。
```

**期待される動き:**
- 8つのファイルを一括分析
- 構造化されたレポートを自動生成
- 数分かかる作業を数秒で完成

---

### 🎯 ボーナス：ファイルへの書き出し

**プロンプト:**
```
上で作成したレポートを「weekly_report.md」というファイルとしてデスクトップに保存してください。
```

> ✨ **ここが感動ポイント！** Claude Code は読むだけでなく、ファイルを新規作成・保存もできます。

## 💼 実践活用事例

デモを体験したあと、実際の業務でどう使えるかのイメージをつかんでもらうための事例集です。

---

### 📂 全職種共通

| シーン | プロンプト例 | 効果 |
|--------|-------------|------|
| バラバラなファイルをまとめて整理 | `デスクトップにある全ファイルを読んで、内容別にフォルダ分けして` | 散在するファイルを自動で分類。数百ファイルでも数分で完了 |
| 複数CSVを横断して集計・レポート化 | `Q1〜Q4の売上CSVを読んで、担当者別・商品別の集計表を作って` | 手作業なら数時間の集計作業が数分で完了 |
| 会議メモからTODO・議事録を自動生成 | `meeting_notes.txtを読んで、担当者別のTODOリストを整理して` | 会議後すぐに整理された議事録・アクションリストを配布できる |
| 大量ドキュメントの横断検索・要約 | `contractsフォルダの契約書を全部読んで、更新期限が3ヶ月以内のものを一覧にして` | 数十の文書を一括確認。見落としのリスクを大幅に削減 |

## 🛠 トラブルシューティング

| 症状 | 対処法 |
|------|--------|
| `claude: command not found` | ターミナルを再起動して再試行 |
| ログインできない | ブラウザでclaude.aiにログインしているか確認 |
| ファイルを読めない | `cd ~/Desktop` でデスクトップに移動してから `claude` を起動 |
| Windows でインストールできない | Git for Windows を先にインストールする |
